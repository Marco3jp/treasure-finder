# Treasure Finder

普段使っている Google Chrome で再生している動画を、画面共有で取り込んで JPEG（品質 90）で残すデスクトップアプリです。16:9 の動画なら **1920×1080** で保存します。

撮影用に別の Chrome を起動しないので、ログイン状態も拡張機能も普段のブラウザのまま撮れます。

## 起動

ホストに Node.js は要りません。配布物は Bun で作った単一実行ファイルです。

Windows なら、ビルド済みの `treasure-finder-win.exe` を置くだけで動きます。

```text
treasure-finder-win.exe
```

起動すると、いつも使っているブラウザで <http://127.0.0.1:47321> が開きます。タブの取り込みができるのは Google Chrome と Microsoft Edge だけなので、ほかのブラウザで開いたときは、この URL を Chrome に貼って開き直してください。

終了は、コンソールで Ctrl+C です。

データを別の場所に置きたいときは、`TREASURE_FINDER_HOME` にそのフォルダを指定します。`data/` はその中に作られます。

### 単一実行ファイルを作る

ビルドするマシンにだけ [Bun](https://bun.sh) が要ります。出来た実行ファイルを動かす側には、Bun も Node.js も要りません。

```bash
bun run build:win
bun run build:mac
bun run build:linux
```

成果物は `dist/` に出ます。Windows 向けは `dist/treasure-finder-win.exe` です。クロスコンパイルできるので、Windows 以外からでも Windows 用を作れます。

### ソースから動かす

```bash
npm start
```

Bun があるなら `bun src/server.js` でも同じです。このときはリポジトリ直下の `data/` を使います。

## 撮り方

1. 動画のページを Chrome のタブで開く
2. 操作パネルの「撮るタブを選ぶ」を押す
3. 共有するものを選ぶ画面で、動画のタブを選んで「共有」を押す（Chrome が動画のタブへ切り替わる）
4. 動画をフルスクリーンにする
5. 操作パネルの「このフレームを撮る」を押す

フルスクリーンのまま撮るときは、手順 3 のあとに操作パネルで「撮影ボタンを最前面のウィンドウに出す」を押しておくと、撮影ボタンだけのウィンドウが手前に残ります。操作パネルか撮影ボタンのウィンドウにフォーカスがあれば、Ctrl+Enter でも撮れます。

撮った JPEG は、実行ファイルと同じ場所の `data/captures/` に入ります。動作確認用のカラーバーは、パネルの「サンプルを開く」からです。

## 撮影

- 共有したタブの表示がそのまま写ります。プレイヤーの操作ボタンや字幕が出ていれば、それも写ります。
- フルスクリーンのプレイヤーは動画を画面の中央に縦横比を保って置くので、画面の縦横比と動画の縦横比から動画の範囲を決めて、中央から切り出します。2560×1600 の画面に 16:9 の動画なら、上下 80px ずつを除いた 2560×1440 の範囲です。
- 取り込みの上限は、切り出す範囲が保存サイズにちょうど届く大きさにします。保存サイズが 1920×1080 なら、16:9 の画面は 1920×1080、16:10 の画面は 1920×1200 です。4K の画面も Chrome が縮めてから取り込みます。
- 切り出した範囲が保存サイズより小さいときは引き伸ばして保存し、そのことを警告に出します。
- 向かい合う縁（上と下、または左と右）が黒以外の同じ色で塗られていたら、ページの背景が写っているとみて「フルスクリーンになっていないかもしれません」と警告します。保存はします。
- パネルのプレビューでは、保存する範囲を青い点線で囲みます。

## 保存の設定

保存サイズは、基準の画面で動画をフルスクリーンにしたときの大きさです。基準の画面（初期値 1920×1080）に、動画の縦横比（初期値 16:9）の範囲を縦横比を保って一番大きく収めた大きさになります。

| 動画の縦横比 | 保存サイズ（基準の画面が 1920×1080 のとき） |
| --- | --- |
| 16:9 | 1920×1080 |
| 4:3 | 1440×1080 |
| 2.39:1 | 1920×803 |

どちらもパネルの「保存の設定」で変えられて、`data/config.json` に残ります。

```json
{
  "screen": { "width": 1920, "height": 1080 },
  "videoAspect": { "width": 16, "height": 9 }
}
```

動画の縦横比が設定と違うと、動画の端が切れるか、黒い帯が残ります。JPEG の品質は 90 で固定です。

## ファイル名

ローカル時刻です。例: `20260928-080509-042.jpg`。同じ名前があれば `-2` から順に付けます。

## テスト

```bash
npm test
```

撮影テストは、Playwright が入れた Chromium（`~/.cache/ms-playwright/chromium-*`）か、`CHROME_PATH` の Chrome をヘッドレスで起動して、別のタブを共有して撮ります。どちらも無ければ飛ばします。
